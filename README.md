# 魔法少女的魔女審判｜無劇透角色百科

## 功能與設計

- 黑紫、暗紅與金色哥德介面；桌面多欄、手機單欄，動畫尊重減少動態效果設定。
- 搜尋中文暫譯名、日文原名、囚人編號及簡介；搭配魔法公開狀態分類與重設條件。
- 點擊整張卡片或使用鍵盤展開／收合公開介紹，提供官方資料來源與返回頂部。
- 13 張角色圖片完整保留日文名字，卡片標題與介紹以中文暫譯名呈現。
- 圖片延遲載入，提供姓名 alt；缺圖時顯示佔位，資料讀取失敗時可重試。

## 規則如何幫助 AI 繼續擴充

AI 必須先讀 `AGENTS.md`、`characters.json` 與 `script.js`，再核對官方公開角色區。每筆角色保留六個必要字串欄位，另有選填 `image`：

```json
{
  "id": "658",
  "name": "桜羽エマ",
  "displayName": "櫻羽艾瑪",
  "description": "樂觀開朗、關心他人的少女；怕寂寞、渴望與人親近，也十分害怕被他人討厭。",
  "magic": "未公開",
  "source": "https://manosaba.com/#character",
  "image": "./assets/characters/658.webp"
}
```

此範例為既有角色，不可重複加入。新增角色時，先確認不重複的 id、官方日文名、20～60 字原創簡介及已公開魔法。未知資料不得猜測，中文名在介面統一標註暫譯。只要更新 JSON，程式就會自動產生卡片、搜尋與分類，不需要為每位角色重寫網頁。

圖片必須先確認有公開網站使用授權，再存入 `assets/characters/<id>.<副檔名>` 並記錄於 `assets/README.md`；尚無素材時 `image` 留空或省略即可。外站圖片、絕對路徑及路徑穿越均不接受。

可重用的 AI 提示：

> 先閱讀根目錄 AGENTS.md，核對官方角色區，依既有格式加入一位尚未收錄的角色。保留所有既有 id，不推測未知資訊；沒有授權圖片就讓 image 留空。測試搜尋、分類、卡片展開、手機排版與錯誤狀態，以獨立分支及 PR 提交，不自動合併。

這套規則清楚區分內容、呈現、授權及驗收，讓後續 AI 能沿用相同方式繼續新增內容。

## 驗收與 GitHub Pages

1. 測試中文、日文、編號、前後空白、無結果及搜尋與分類交集；重設應顯示全部 13 位。
2. 以滑鼠、Tab、Enter／空白鍵測試卡片與官方連結，確認圖片、姓名與角色對應。
3. 檢查 320～1440px 無水平溢出、手機單欄、圖片完整顯示、返回頂部及減少動畫。
4. 模擬 JSON 錯誤與 HTTP 失敗，重試應可恢復；圖片 404 應回復佔位。
5. 以 PR 審查後才合併至 main。GitHub Settings → Pages → Deploy from a branch → main / (root) → Save。

Pages 網址為 `https://andyyy845.github.io/witch-trial-wiki/`。完整網站在 PR 合併及部署完成前不會公開顯示；無需修改原《無職轉生》專案設定。
